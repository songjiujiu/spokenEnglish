# 初语｜本地学习版

这是依据《初语_零基础到雅思8_Web开发文档.md》重新建立的本地优先项目基线。原交付源码不在当前仓库，因此本项目不声称包含原程序的 30 组课程或历史数据兼容能力。

## 运行

需要 Node.js 18+。在项目目录运行 `npm run dev` 启动本地服务，浏览器访问 `http://127.0.0.1:8765`。运行 `npm run build` 校验课程并生成 `初语_学习程序.html`，运行 `npm test` 执行仓库自动化测试。请通过本地服务访问源码版，不要直接用 `file://` 打开。

## 当前实现

- 两册学习路线：按实际读取的本地资料设计，用户确认每天 45 分钟、每周 6 天。包含 12 个阶段、102 周参考排课、首周逐日任务、复盘周和 18 个资源路径，可筛选和打印。
- 暖白与深绿的中文学习界面、今日任务、六阶段路线和练习列表。
- 首页按每日时长分配看课及五步练习预算，支持桌面与手机布局。
- 新概念资源页：收录外研社与北京新东方的 5 个资料入口，注明来源、核查日期与访问条件；视频实际播放未核验。
- 原创入门练习和五步流程：听一听、弄明白、说出来、写下来、想起来。
- 回忆检查为每组练习生成 3 张表达复习卡；重复检查沿用已有卡片，不重复建卡或清空复习记录。
- 复习页提供到期、全部和错题视图，支持自建卡、翻面及三档自评间隔安排。自评用于安排下次练习，不代表语言水平或掌握认证。
- 理解题和回忆检查中的错误进入错题记录，保留最近作答，支持查看参考答案与自行标记解决。
- 本机保存、JSON 备份、导入预览和异常摘要；备份包含复习卡、错题、设置、进度和草稿。
- 保存异常以持久提示显示；导入替换前保护旧数据快照，快照失败时停止替换。多标签页冲突会暂停写入，但不承诺任意并发竞态下的数据同步。
- 课程结构构建校验与 Node.js 标准库测试；本轮验收结果见 `测试说明.md`。
- 网盘地址与提取码不设公开默认值；不含服务器、账号、云同步或 AI 评分。

当前课程数据为 6 组原创练习，尚非文档中所述的 30 组课程。为保护旧程序可能留下的数据，本重建版使用独立的浏览器存储键，并在备份中带有格式标识；不会读取或覆盖原程序的键值。此前重建版生成的备份可以导入，缺少的复习卡和错题字段会按空集合处理；这不表示兼容缺失源码的原程序备份。

## 复习与备份

在练习的“想起来”步骤填完 3 条表达并检查，随后进入“复习与错题”查看卡片。到期视图用于当天复习，全部视图用于查看卡库；翻面后按本次回忆表现选择档位。自建卡可填写自己需要复习的提示和答案。错题视图保留最近一次错误作答，确认复习后可自行标记解决；重答正确也会标记解决，并保留之前的错误内容。

复习间隔：没想起来为 10 分钟后，需要提示为 1 天后；独立想起依次使用 1、3、7、14、30、60 天的间隔。初次生成的卡片立即到期。可以从“全部卡片”提前复习，下一次日期从本次作答时间计算。

进度、卡片和错题保存在当前浏览器。出现保存异常提示时，请先下载本页备份；此时页面上的修改可能尚未写入设备。导入前先阅读替换预览和清洗摘要，确认旧快照已妥善保存；浏览器发起下载不等于文件已经落盘。“数据与设置”提供“下载上次导入前的快照”入口，最近一次快照会保留到下一次导入。重新打开页面后，存储成功的内容和复习日期会恢复。

视频播放器、录音、自动评分、完整 30 组课程和云同步尚未实现。新概念资源仍是外部资料入口，尚未验证真实设备上的外部音视频播放。

## 新概念一、二册的本地学习规划

打开左侧“两册学习路线”，或直接双击项目中的 `两册学习路线与规划.html`。规划页可查看每周课号、首周六天任务、第一册与第二册周模板、复盘周及对应本地资料路径。复制路径到 Windows 文件资源管理器即可打开原文件；规划页不直接播放视频。

资料来自用户指定的 `D:\BaiduNetdiskDownload\新概念一` 与 `新概念二`。本轮盘点 4,123 个文件，约 52.22 GiB；没有搬运、修改或上传这些教材和视频。第一册是 144 课 / 72 对课；第二册是 96 课。多个版本的音频、同课的讲解分片和拓展资料不重复计为新课程。

参考安排：2 周发音起步 + 第一册 42 周（36 教学、6 复盘）+ 2 周衔接 + 第二册 56 周（48 教学、8 复盘）= 102 周。每周共 270 分钟，视频按需选看，最长 90 分钟；其余时间做听读、表达、练习和复习。长课或隔天无法独立输出时顺延，102 周不是完成期限或英语等级保证。

学习规划是根据资料设计的排课；教材课号目前不写入站内原创练习进度。首周、阶段门槛与口语时长为本项目设计，第二册具体摘要要求仍以对应教材题目为准。

资料依据和分片时长保存在 `planning/materials-inventory.json`、`planning/book1-audit.json`、`planning/book2-audit.json` 与 `planning/book2-video-audit.json`。规划源数据为 `src/study-plan-data.json`。修改规划逻辑后依次运行 `node scripts/make-study-plan.mjs`、`npm run build`；只有资料目录实际变化时才需要重新运行 `node scripts/scan-materials.mjs` 并复核时长审计。

## 开发

编辑源码或 `src/course-data.json` 后运行 `npm run build`。运行 `npm test` 执行现有自动化测试，覆盖范围和待手工验收事项见 `测试说明.md`。生成的单文件不应手工修改。

资源目录编辑源为 `src/resource-data.json`；新增页面样式位于 `src/design.css`。页面设计约定和剩余范围见 `设计说明.md`。
